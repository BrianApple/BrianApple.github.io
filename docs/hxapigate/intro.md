# HXAPIGate（浩心 API 网关）产品介绍

## 产品定位

HXAPIGate（中文名：**浩心 API 网关**）是一款基于 **Netty + Shiro** 开发的高性能 API 网关，本质上是一个面向 REST 服务的**细粒度 API 资源权限管理平台**，支持 HTTP、Dubbo、MCP、WebSocket 等多协议微服务接口代理。

HXAPIGate 采用「零侵入」设计：业务微服务无需引入任何网关 SDK、无需改造代码，发布后由网关统一赋予鉴权、限流、熔断、负载均衡等分布式特性。管理平台（HXBootShiro）负责 API 路由与鉴权规则的统一管理；网关集群节点通过 Redis 进行分布式限流与配置同步（已移除对 Ignite 的依赖）。

## 更新说明（当前版本）

1. 新增 **WebSocket 双向透传代理**：管理端协议类型新增 `WebSocket`（节点配置型，含负载均衡/TPS/熔断），网关自动识别 `Upgrade: websocket` 握手并按 WS 方法匹配路由，支持双向帧转发、后端推送、断开传播与可配置空闲超时（`HXAPI_WS_IDLE_TIMEOUT`，默认 60s）
2. **安全加固**：JWT 签名密钥外置化（环境变量 `HXAPI_JWT_SECRET` 注入，管理端与网关共用）、数据库口令环境变量化
3. **死代码清理**：移除 5 个无调用接口（`/account/login`、`/inner/api/islogin` 等）及对应 Service/Mapper 层
4. **前端改造**：Vue3 + Element Plus 全面改造（登录页粒子动画、API 两级类型、角色授权双栏等）
5. **技术栈升级**：JDK 21 + Shiro 3.0 + jjwt 0.12，移除 Ignite 依赖
6. **可靠性增强**：增加接口熔断功能，同时对新增接口的路由信息增加安全限制保障服务运行安全

## 软件特色：「API 资源 + 请求方式」细粒度授权

目前多数授权管理平台都只对 API 路径资源本身授权，做不到更细粒度的权限控制。HXAPIGate 通过组合 BootShiro 实现了「**API 资源 + 请求方式**」的授权模式。

例如新增如下四个接口：

| 接口路径 | 请求方式 |
|--|--|
| `/user/list` | GET |
| `/user/list` | POST |
| `/user/list` | DELETE |
| `/user/list` | PUT |

传统授权模式下，这四个接口会因路径一致被当做一个接口整体授权给第三方；而通过 HXAPIGate 可以**分别对每个资源独立授权**——当仅仅授权 `/user/list` + `GET` 给第三方平台时，被授权方无法访问同一资源的 POST、DELETE、PUT 请求。

## MECHA（机甲）思想

浩心网关是微服务思想结合 **MECHA 机甲思想**落地的产物。如下图所示，内部浅绿色区域为业务相关微服务区，浩心网关所在区域为外部**分布式特性区域**：

- 微服务**不需要考虑任何分布式特性**，更不需要在服务的生命周期中引入与业务功能不相关的第三方分布式组件（典型如 Spring Cloud 全家桶）
- 当一个业务微服务单元发布之后，浩心网关会**直接赋予该服务所有分布式组件特性**

![MECHA 机甲架构图](/img/hxapigate/mecha.png)

这一思想与 Service Mesh 有神似之处，将浩心网关打造成工业级 sidecar 也是项目目标之一。

### 为什么不选择 Spring Cloud 或 Dubbo

- **不选择 Spring Cloud**：除非贵公司项目全是新上马的项目、没有任何历史遗留问题——即便果真如此，Spring Cloud 的学习成本等因素在某些情况下也不建议使用。考虑到很多公司存在历史遗留问题、无法改用 Spring Cloud，HXAPIGate 可以在**不更改或极少更改**代码的情况下，为存量服务实现分布式限流、服务熔断等分布式特性。
- **不选择 Dubbo**：HXAPIGate 其实兼容了 Dubbo 协议——用户侧统一为 HTTP 协议，因此虽然 API 网关本身不对外提供 Dubbo 服务，但可以代理 Dubbo 微服务，同时也可以实现对 Dubbo 的分布式限流。

## 功能架构与部署结构

HXAPIGate 支持**集群部署**，支持被代理接口的分布式限流与负载。分布式部署时网关节点通过 Redis 进行分布式限流与配置同步，管理平台（HXBootShiro）负责 API 路由与鉴权规则的统一管理。

## 当前已实现功能

1. 授权、鉴权管理（JWT 密钥支持环境变量外置注入）
2. 路由配置（支持熔断参数 UI 可视化配置：失败阈值/成功阈值/超时毫秒）
3. 路由负载（轮询和赋权值）
4. HTTP、Dubbo、MCP、WebSocket 多协议代理（WebSocket 支持双向透传/后端推送/断开传播/可配置空闲超时）
5. 接口分布式限流（Redis 计数信号量）
6. 金丝雀发布
7. 接口熔断（状态机管理，配置值优先于 TPS 自动推导）
8. 管理平台首页统计（ECharts 类型分布/接口状态图表）
9. 网关核心单元测试（限流/负载均衡/熔断状态机）

MCP 协议转换、WebSocket 双向透传、文件上传/下载代理、接口熔断与分布式限流等高级特性，详见[高级特性专题](./features)。
:::

## 项目进度

目前 HXAPIGate 网关对 API 接口的管理已基本开发完成，后续主要对 API 接口支持的代理协议以及网关 bug 进行扩展和完善，同时扩展管理平台功能。已完成一轮安全加固与质量优化：JWT 密钥与数据库口令环境变量化、死代码清理（−423 行）、网关核心单测补充（14 用例全通过）、API 熔断配置 UI 全链路打通、首页统计可视化升级。
