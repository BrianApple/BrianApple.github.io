# IOTGate 智能物联网网关

![IOTGate 项目 Logo](/img/iotgate/iotgate-logo.png)

IOTGate 是基于 **Netty** 实现的自定义协议物联网网关，支持**单机与集群**两种部署形态，是物联网感知设备网络入口的核心组件。它与前置（master）节点通信，负责终端设备的接入、心跳保活、真实报文转发，并通过自定义网关头结构完成网关登录与数据上报。

## 产品定位

- **高性能**：window 笔记本电脑本地测试，**单网关 + 单前置节点**每秒处理并发心跳 **8000+**（根据 jmeter 本地最新压测统计数据），**20W 在线终端**（长连接保持）内存占用量 **1G 左右**
- **多规约**：默认支持 modbus TCP、IEC 104、DLT 645 等应用层通信规约，支持本地配置与远程管理
- **可集群**：通过命令行参数动态配置网关为单节点或集群，集群版默认心跳周期 300 秒
- **AI 智能体**：v3.0.1 起内置 LangChain4j AI 智能体，粘贴协议帧结构描述即可自动推导拆包/黏包解码参数并**一键创建规约**

:::note
通信规约即应用层通信协议，与通常所说的"通信协议"是同一个意思。本项目的使用有一定门槛，需要具备一定的物联网应用层协议知识，比如大小端、长度域等等。
:::

## v3.0.1 核心亮点

IOTGate 正式声明为 **AI 智能体版本（v3.0.1）**，与 IOTGateConsole 智能体控制台配套，形成「网关 + AI 智能体管理平台」完整部署形态：

- **AI 智能体（LangChain4j）**：粘贴协议**帧结构描述**，大模型自动提取长度域信息、推导拆包/黏包解码参数，一键创建规约；支持**流式思考过程**、**多轮对话**、**多模型切换**与**对话记录落库**
- **初/高级规约自动判断**：自动识别该协议适用基础规约还是高级规约（自定义长度域解析），高级规约可直接一键创建
- **控制通道反转**：网关不再主动注册/上报状态，改由控制台**主动探针**判活（10s）+ **主动下发**指令（HTTP 10917）
- **规约远程管理**：在线开启/关闭/新增/删除多规约解析服务，变更实时同步网关
- **大模型厂商无关**：支持 DeepSeek / 通义 / GLM / Ollama 等任意 OpenAI 兼容接口，可视化配置即时生效

## 功能架构

![IOTGate 开源版功能架构图](/img/iotgate/architecture-overview.jpeg)

终端设备经网关接入，网关以自定义网关头报文与前置通信；控制台侧通过 HTTP 指令通道（网关 10917 端口）主动探针与下发指令，实现节点监控与规约远程管理。

## 适用场景

- 物联网感知设备的统一接入与长连接管理（百万级设备长连接）
- 多规约（modbus TCP / IEC 104 / DLT 645 等）终端报文的解析与转发
- 需要"网关 + 管理平台"闭环运维的物联网项目，配合 IOTGateConsole 实现节点监控、规约启停、AI 辅助配置
- 基于大模型 MCP 协议的智能通信网关演进（v3.x 规划中）

## 版本沿革

| 版本 | 说明 |
|---|---|
| **v1.0** | 集群版网关程序，通过命令行参数动态配置网关为单节点或集群（单节点不依赖 zookeeper 集群），网关与前置通讯时默认轮询方式负载均衡 |
| **v2.0.1.release** | IOTGate 第一个正式稳定版本，可用于生产环境直接运行 |
| **v2.0.2.release** | 解决了一些 bug，优化了内存泄漏异常，单机版本增加配置单个规约心跳的配置选项，不同规约心跳管理更加灵活 |
| **v2.0.3** | IOTGate 第一个正式发行版，提供可执行 jar 包与前置网关演示 demo 下载 |
| **v2.2** | AI 智能体过渡版本，内置 LangChain4j AI 智能体，与 IOTGateConsole v2.2 智能体控制台配套 |
| **v3.0.1（当前）** | 正式声明 **AI 智能体版本**：去 Zookeeper（`-m` 直连前置）、**控制通道反转**（Console 主动探针 + HTTP 10917 指令）、流式思考 / 多轮对话 / 多模型 / 对话落库、初高级规约自动判断与一键创建 |
| **v3.x（开发中）** | IOTGate 智能物联网通信网关，支持大模型 MCP 协议，实现基于大模型交互对话以创建 IOTGate 通信协议代理 |
