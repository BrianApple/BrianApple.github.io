# IOTGate 产品介绍

## 产品定位

IOTGate 是一款基于 **Netty** 实现的自定义协议物联网网关，同时支持**单机版**和**集群版**两种部署形态。它处于物联网架构中的"感知网络接入层"：终端设备通过 TCP 长连接接入网关，网关负责解析不同厂商、不同规约（应用层通信协议）的报文，并将真实报文转发给前置（master）服务。

IOTGate 由个人开发者维护，以 GPL-2.0 协议开源。项目入口类为 `Entrance.java`，通过命令行参数即可动态配置网关的运行模式，无需修改代码。

:::note
项目 README 中特别提醒：使用本项目有一定门槛，需要使用者具备一定的物联网应用层协议知识，例如**大小端、长度域**等概念。
:::

## 核心特性

### 高并发连接能力

IOTGate 基于 Netty 实现高并发长连接管理，官方在 Windows 笔记本上（堆内存 2G、线程数 6K）实测：

- 单网关、单前置节点，每秒处理并发心跳 **8000+**
- **20 万**在线终端（长连接保持）时内存占用约 **1G** 左右

### 多规约解析机制

网关通过本地配置文件 `iotGate.conf` 同时管理多套规约解析规则，每条规则独立配置**大小端、起始符、长度域偏移、长度域长度、端口号、心跳周期**等参数，互不干扰。默认内置支持 modbus TCP、IEC 104、DLT 645 等常见规约的配置示例。

### 单机 / 集群双模式

- **单机版**：命令行参数 `-m` 指定前置服务地址，数据通道零依赖
- **集群版**：自 v2.0 起去除 Zookeeper 依赖，通过 `-m` 直连前置（支持逗号分隔多个前置地址），网关与前置通讯时默认采用**轮询方式负载均衡**

### 心跳检测

单机版可以通过配置文件为每个规约个性化配置心跳周期；集群版默认心跳为 **300 秒**。

### AI 智能体（v2.2）

v2.2 版本正式升级为 AI 智能体版本，与 IOTGateConsole 智能体控制台配套，形成"网关 + AI 智能体管理平台"完整部署形态：

- **AI 智能体（LangChain4j）**：粘贴协议帧结构描述，大模型自动提取长度域信息、推导拆包/黏包解码参数，一键填充规约表单
- **动态节点发现**：网关 `-c -r` 主动注册 + 10s 心跳 + 404 自愈重注册，控制台实时监控节点状态
- **规约远程管理**：在线开启/关闭/新增/删除多规约解析服务，变更实时同步网关
- **大模型厂商无关**：支持 DeepSeek / 通义 / GLM / Ollama 等任意 OpenAI 兼容接口，可视化配置即时生效

## 适用场景

- **物联网设备接入汇聚**：各类传感器、采集终端通过 TCP 长连接接入，网关统一管理连接生命周期
- **多规约统一解析**：现场存在多种应用层协议的设备，需要在一个网关内同时解析并转发
- **大规模长连接场景**：需要支撑数十万级在线终端、每秒数千级心跳的接入场景
- **网关集群管理**：需要将多个网关节点纳入统一管理平台（IOTGateConsole）进行监控与规约远程维护

## 在开源体系中的位置

IOTGate 与 **IOTGateConsole** 是两个独立的开源工程，二者可选搭配组合成完整部署形态：

| 形态 | 说明 |
|------|------|
| 仅网关（最小部署） | 只用 `-m` 直连前置，无需管理平台，数据通道零依赖 |
| 网关 + 管理平台（推荐） | 网关 `-c -r <consoleIp>` 主动注册到 IOTGateConsole，Console 提供节点监控、规约启停管理、AI 智能体等能力，形成完整的"网关-控制台"管理闭环 |

IOTGateConsole 是一个 Spring Boot 3.5 Web 工程，默认端口 **8686**，项目地址：https://gitee.com/willbeahero/IOTGateConsole

此外，作者还开源了基于 Netty + Shiro 的零侵入式 API 网关 **HXAPIGate**，以及商业化的浩欣泛在物联网云平台（设备侧采用 IOTGate 企业版作为感知设备网络入口），共同构成完整的物联网接入技术栈。

## 版本沿革

- **v1.0**：集群版网关程序，通过命令行参数动态配置单节点或集群（单节点不依赖 Zookeeper）
- **v2.0.1.release**：第一个正式稳定版本，可用于生产环境直接运行
- **v2.0.2.release**：修复反馈的 bug，优化内存泄漏异常；单机版增加按规约配置心跳的选项
- **v2.0.3**：第一个正式发行版，提供可执行 jar 包下载
- **v2.2（2026-08）**：AI 智能体版，内置 LangChain4j AI 智能体，与 IOTGateConsole v2.2 智能体控制台配套
- **v3.x**：开发中，支持大模型 MCP 协议，实现基于大模型交互对话创建 IOTGate 通信协议代理
