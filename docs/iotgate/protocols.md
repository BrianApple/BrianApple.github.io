# 多规约支持

"真实报文"即终端与网关通信时传输数据的报文，规约不同则报文结构差异明显。IOTGate 支持多规约的本地配置，以及通过 IOTGateConsole 远程开启/关闭/新增/删除网关多规约解析服务。

## 默认支持的两种真实报文

网关配置文件中默认支持两种真实报文结构：

### 规约编号 1

| 报文属性 | 字节数 | 含义 |
|---|---|---|
| `68` | 1 byte | 报头 |
| `len` | 2 byte | 长度域："传输帧中除起始字符 68 和结束字符 16 之外的帧字节总数，包含长度域本身字节数" |
| `data` | n byte | 报文内容 |
| `16` | 1 byte | 报尾 |

### 规约编号 2

| 报文属性 | 字节数 | 含义 |
|---|---|---|
| `len` | 4 byte | 长度域值为 data 的字节数，不包含自身字节数 |
| `data` | n byte | 报文内容 |

:::note
长度域是拆包/黏包解码的核心参数：规约 1 的长度"包含长度域本身字节数"，规约 2 的长度"不包含自身字节数"，两者在配置时需严格区分。
:::

## 内置规约示例

### modbus TCP

报文结构：

![modbus TCP 报文结构](/img/iotgate/modbusTCP.png)

配置信息：

```properties
1,1,-1,4,2,0,0,9813,60
```

### IEC 104

配置信息：

```properties
2,1,-1,1,1,0,0,9814,60
```

### DLT 645

配置信息：

```properties
3,0,-1,9,1,0,2,9815,60
```

:::tip
配置信息中的参数依次对应规约编号、大小端、长度域偏移/长度等拆包解码参数，末尾为规约监听端口与心跳周期，可在 IOTGateConsole 规约管理页在线维护。
:::

## 如何接入新规约

- **本地配置**：在 `iotGate.conf` 中按上述格式追加新的规约配置行，重启网关生效
- **远程管理（推荐）**：通过 IOTGateConsole 规约管理页在线**新增/删除/开启/关闭**规约解析服务，规约参数（大小端、长度域偏移/长度、端口等）在线维护，**变更实时同步到网关**，无需重启

## AI 辅助配置规约

v2.2 起，配置新规约不再需要手工推导拆包/黏包参数：

1. 在 IOTGateConsole 中呼出右下角 🤖 悬浮智能体机器人
2. 粘贴通信协议的**帧结构描述**（协议文档中的字段定义：帧头、各字段字节数、**长度域位置与定义**、字节序、校验帧尾等）
3. AI 自动提取长度域信息，推导出网关拆包/黏包解码参数（大小端/起始符/长度域偏移/长度域长度/长度含长度域标志/额外长度/端口）
4. **一键填充**到新增规约表单，保存后实时同步网关
