# IOTGateConsole 产品介绍

## 产品定位

IOTGateConsole 是 **IOTGate 智能网关的控制台程序**（GATE CLIENT），用于：

- 查看当前 IOTGate CLUSTER（网关集群）的运行状态监控
- 执行网关**规约解析服务的启动、关闭、重启**操作
- 进行**网关多规约策略配置**（新增、删除、更新规约）

它与 IOTGate 网关是两个独立工程，组合成"网关 + AI 智能体管理平台"的完整部署形态。项目地址：https://gitee.com/willbeahero/IOTGateConsole

:::note
README 明确说明：目前不考虑监控网关服务器状态（如 CPU、内存等服务器指标）功能，控制台聚焦于网关节点与规约的管理。
:::

## 核心能力

### 集群状态监控

- **节点管理**：实时展示网关节点列表，区分**动态注册**（网关 `-c -r` 主动注册，含最近心跳、在线时长）与**静态配置**（`application.properties` 中 `gate.nodes` 兜底）两种来源
- **在线状态**：由 NodeMonitorService 定时 TCP 探测得出（每 10s 一次，探测节点 10916 RPC 端口，2s 超时），动态注册节点与静态配置节点无差别对待
- **SSE 实时推送**：节点上下线状态、规约变更事件通过 SSE（`GET /rpc/events`）实时推送到前端

### 规约远程管理

在线**开启/关闭/新增/删除**网关多规约解析服务，规约参数（大小端、长度域偏移/长度、端口等）在线维护，变更**实时同步到网关**。

### AI 智能体（v2.2）

控制台内置右下角**悬浮智能体机器人**，集对话解析与大模型配置管理于一体：

- **对话解析**：粘贴通信协议的帧结构描述，AI 自动提取长度域信息，推导网关拆包/黏包解码参数，并支持**一键填充**到新增规约表单
- **大模型配置动态设置**：厂商无关，支持任意 OpenAI 兼容接口（DeepSeek / 通义千问 / 智谱GLM / Ollama / OpenAI 等），可视化修改模型地址、模型名称、API Key、采样温度、超时时间，**保存立即生效，无需重启**，配置持久化本地（重启后保留）

## 技术栈

- **后端**：JDK 21 + Spring Boot 3.5
- **前端**：Vue3 + Vite 单页应用（源码位于 `frontend/` 目录，构建产物集成到 `src/main/resources/static/`）
- **AI**：LangChain4j 1.18（AiServices 声明式结构化输出），Java 8 老项目平滑升级至 JDK 21 + Spring Boot 3.5
- **数据库**：MySQL 5.5+（默认连接 `127.0.0.1:13306/iotgatedb`）
- **通信**：SSE 实时推送 + RPC（经网关 10916 端口调用规约启停等操作）

## 架构变更说明（v2.0）

本版本对架构做了两项重要调整：

1. **去除 Zookeeper 依赖**：网关节点发现不再依赖 ZK 注册中心，改为**网关主动注册 + 静态配置兜底**双通道
2. **前端 Vue3 重构 + SSE 实时推送**：原 LayUI/jQuery 静态页面重构为 Vue3 + Vite 单页应用；前端通过 SSE 实时接收网关节点上下线状态、规约变更事件，替代原 ZK 事件监听机制

### 节点发现双通道

- **动态注册（推荐）**：网关启动时通过 `-c -r <consoleIp>` 主动注册到本控制台（`POST /gate/register`），注册成功后每 10s 心跳上报（`POST /gate/heartbeat`），30s 未收到心跳自动判离线并移除；网关正常关闭时主动反注册（`POST /gate/unregister`）。注册成功即自动同步规约，前端节点管理页实时可见
- **静态兜底**：`application.properties` 中 `gate.nodes` 配置网关节点 IP 列表（支持 `ip` 或 `ip:port` 格式，默认 RPC 端口 10916），与动态注册并存，**注册的节点优先、静态配置兜底**

## 版本演进

| 版本 | 核心能力 | 智能体形态 | 技术栈 |
|------|---------|-----------|--------|
| v2.0 | 去 Zookeeper、Vue3 重构、SSE 实时推送 | 无 | Spring Boot 2.x + JDK 8 |
| v2.1 | 新增智能体模式：AI 解析协议帧结构、自动填充规约表单 | 页面内嵌面板 | LangChain4j 初版集成 |
| v2.2（当前） | 悬浮机器人 + 大模型配置动态化 + 节点/规约管理增强 | 右下角悬浮机器人 | JDK 21 + Spring Boot 3.5 + LangChain4j 1.18 |

v2.2 相比 v2.1 的重要更新：

1. 交互形态升级为右下角悬浮机器人（主流客服交互设计，带呼吸脉冲动画）
2. 大模型配置动态化：模型地址/模型名称/API Key/温度/超时可视化修改、保存立即生效、无需重启
3. 厂商无关化：支持任意 OpenAI 兼容接口，v2.1 仅内置 DeepSeek 单一厂商
4. 技术栈升级：JDK 8 → 21、Spring Boot 2.x → 3.5
5. 界面焕新：登录页升级为 AI 智能体版科技风格，悬浮机器人图标替换为 SVG 矢量图
6. 运行管理增强：规约启停管理落地、节点管理页增强、网关主动注册机制

:::note
v2.1 → v2.2 为增量演进，v2.1 的 AI 解析帧结构、一键填充规约表单等核心能力在 v2.2 中原样保留并增强。
:::
