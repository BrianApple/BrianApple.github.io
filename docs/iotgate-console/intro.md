# IOTGateConsole 智能网关控制台

IOTGateConsole 是 IOTGate 智能网关的**控制台程序**，用于查看当前 IOTGate CLUSTER 的运行状态，执行网关规约解析服务的**启动、关闭、重启**以及**网关多规约策略配置**等操作。

## 产品定位

- **运行状态监控**：实时展示网关节点列表、在线状态、运行规约、最近心跳、在线时长
- **规约远程管理**：在线开启/关闭/新增/删除网关多规约解析服务，变更实时同步网关
- **AI 智能体**：内置 LangChain4j 悬浮机器人，粘贴协议帧结构描述即可自动生成拆包/黏包解码参数并一键填充规约表单
- **节点自动发现**：网关主动注册 + 静态配置兜底双通道，SSE 实时推送节点上下线与规约变更

## 核心能力

- **动态注册（推荐）**：网关启动时通过 `-c -r <consoleIp>` 主动注册到本控制台（`POST /gate/register`），注册成功后每 10s 心跳上报（`POST /gate/heartbeat`），30s 未收到心跳自动判离线并移除；网关正常关闭时主动反注册（`POST /gate/unregister`）。注册成功即自动同步规约，前端节点管理页实时可见
- **静态兜底**：`application.properties` 中 `gate.nodes` 配置网关节点 IP 列表（支持 `ip` 或 `ip:port` 格式，默认 RPC 端口 10916），与动态注册并存，注册的节点优先、静态配置兜底
- **SSE 实时推送**：前端通过 SSE（`GET /rpc/events`）实时接收网关节点上下线状态、规约变更事件
- **AI 对话解析**：智能体自动提取长度域信息，推导拆包/黏包解码参数（大小端/起始符/长度域偏移/长度域长度/长度含长度域标志/额外长度/端口），一键填充到新增规约表单

## 功能总览

| 功能 | 说明 |
|---|---|
| **节点管理** | 实时展示网关节点列表，区分动态注册与静态配置两种来源，展示运行规约、最近心跳、在线时长 |
| **规约管理** | 远程开启/关闭/新增/删除网关多规约解析服务，参数在线维护，变更实时同步网关 |
| **AI 智能体** | 悬浮机器人对话解析协议帧结构，自动生成拆包/黏包解码参数并一键填充规约表单 |
| **大模型配置** | 厂商无关，可视化修改模型地址/名称/Key/温度/超时，保存立即生效 |
| **SSE 实时推送** | 节点上下线、规约变更事件实时推送前端 |

## v2.0 架构变更说明

本版本对架构做了两项重要调整：

1. **去除 Zookeeper 依赖**：网关节点发现不再依赖 ZK 注册中心，改为**网关主动注册 + 静态配置兜底**双通道
2. **前端 Vue3 重构 + SSE 实时推送**：原 LayUI/jQuery 静态页面已重构为 Vue3 + Vite 单页应用；前端通过 SSE（`GET /rpc/events`）实时接收网关节点上下线状态、规约变更事件，替代原 ZK 事件监听机制

## 版本演进（v2.0 → v2.1 → v2.2）

本仓库在 v2.0 基础上完成了从"无 AI"到"智能体全功能版"的三级演进：

| 版本 | 核心能力 | 智能体形态 | 技术栈 |
|---|---|---|---|
| **v2.0** | 去 Zookeeper、Vue3 重构、SSE 实时推送 | ❌ 无 | Spring Boot 2.x + JDK 8 |
| **v2.1** | 新增智能体模式：AI 解析协议帧结构、自动填充规约表单 | 页面内嵌面板 | LangChain4j 初版集成 |
| **v2.2（当前）** | 悬浮机器人 + 大模型配置动态化 + 节点/规约管理增强 | 右下角悬浮机器人 | JDK 21 + Spring Boot 3.5 + LangChain4j 1.18 |

**v2.2 相比 v2.1 的重要更新：**

1. **交互形态升级**：智能体由页面内嵌面板改为**右下角悬浮机器人**（主流客服交互设计，带呼吸脉冲动画），随时呼出、随时收起，不占页面空间
2. **大模型配置动态化**：模型地址/模型名称/API Key/温度/超时**可视化修改、保存立即生效、无需重启**，配置持久化本地；v2.1 只能改配置文件重启生效
3. **厂商无关化**：支持任意 OpenAI 兼容接口（DeepSeek / 通义千问 / 智谱GLM / Ollama / OpenAI），v2.1 仅内置 DeepSeek 单一厂商
4. **技术栈升级**：JDK 8 → **21**、Spring Boot 2.x → **3.5**、LangChain4j 规范化重构（AiServices 声明式结构化输出），性能与可维护性全面提升
5. **界面焕新**：登录页升级为 AI 智能体版科技风格（突出百万设备长连接与多规约接入）、页面新增 v2.2 版本标识、悬浮机器人图标由 emoji 替换为 **SVG 矢量图**（修复无 emoji 字体环境下显示为 × 的问题）
6. **运行管理增强**：规约启停管理落地、节点管理页增强（注册来源/最近心跳/在线时长/运行规约展示）、网关主动注册机制（动态发现 + 静态配置兜底）

:::note
v2.1 → v2.2 为增量演进，v2.1 的 AI 解析帧结构、一键填充规约表单等核心能力在 v2.2 中原样保留并增强。
:::

## 技术栈

- **JDK 21**（Temurin 21 LTS 及以上）+ **Spring Boot 3.5**
- **LangChain4j 1.18**（AiServices 声明式结构化输出）
- 前端 **Vue3 + Vite** 单页应用（原 LayUI/jQuery 静态页面已重构），构建产物集成到 `src/main/resources/static/`
- **MySQL 5.5+**（规约策略存储）
- 入口类：`IotGateConsoleApplication`
