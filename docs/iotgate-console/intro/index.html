IOTGateConsole 智能网关控制台

IOTGateConsole 是 IOTGate 智能网关的控制台程序，用于查看当前 IOTGate CLUSTER 的运行状态，执行网关规约解析服务的启动、关闭、重启以及网关多规约策略配置等操作。

产品定位​

  • 运行状态监控：实时展示网关节点列表、在线状态、运行规约与探针结果
  • 规约远程管理：在线开启/关闭/新增/删除网关多规约解析服务，变更实时同步网关
  • AI 智能体：内置 LangChain4j 悬浮机器人，粘贴协议帧结构描述即可自动推导拆包/黏包解码参数并一键创建规约（支持流式思考、多轮对话、多模型切换）
  • 实时推送：SSE 实时推送节点上下线与规约变更

核心能力​

  • 节点登记与探活：在「节点管理」页登记网关 IP 与指令端口（默认 10917），Console 每 10s 通过 HTTP 探针 GET /gate/status 取运行快照判活；网关侧无需任何 Console 配置
  • 控制通道主动下发：规约新增/启停/删除均通过 POST /gate/command 由 Console 主动下发；探针发现网关缺规约时自动补发
  • SSE 实时推送：前端通过 SSE（GET /rpc/events）实时接收节点上下线状态、规约变更事件
  • AI 对话解析：智能体流式返回思考过程与结构化结果，自动判断基础/高级规约；基础规约一键填充表单，高级规约直接创建

功能总览​

功能说明
节点管理展示网关节点列表与在线状态，新增/删除节点（IP + 指令端口），展示运行规约与探针失败原因
规约管理远程开启/关闭/新增/删除网关多规约解析服务，参数在线维护，变更实时同步网关
高级规约维护自定义长度域解析实现（网关侧运行时动态编译），适配非固定长度域报文
AI 智能体悬浮机器人对话解析协议帧结构，自动推导解码参数并一键创建规约；支持流式思考、多轮对话、停止中断
多模型配置厂商无关，可配置多个模型并在对话面板随时切换；API Key 脱敏回显
对话记录每轮问答（含思考过程）落库，可按会话回看
SSE 实时推送节点上下线、规约变更事件实时推送前端

架构变更说明​

  1. 去除 Zookeeper 依赖：不再依赖 ZK 注册中心
  2. 前端 Vue3 重构 + SSE 实时推送：原 LayUI/jQuery 静态页面重构为 Vue3 + Vite 单页应用；前端通过 SSE（GET /rpc/events）实时接收节点上下线与规约变更事件，替代原 ZK 事件监听机制
  3. 控制通道反转（v3.0.2）：由「网关主动注册 + 心跳上报」改为「Console 主动探针 + 主动下发指令」；网关侧 -c -r 参数、原 RPC 端口 10916、以及控制台的 RPC 调用链均已移除
  4. 前端构建集成进 Maven（v3.0.2）：mvn package 一次构建 = 前端 + 后端打进同一个 jar

集群整体架构​

GATE Console 是一个 Web 工程，用户登录之后可以查看当前 GATE CLUSTER 的运行状态监控，执行网关重启、关闭、启动，网关多规约支持策略等操作（目前不考虑监控网关服务器状态功能）。

版本演进（v2.0 → v2.1 → v2.2 → v3.0.1 → v3.0.2）​

版本核心能力智能体形态技术栈
v2.0去 Zookeeper、Vue3 重构、SSE 实时推送❌ 无Spring Boot 2.x + JDK 8
v2.1新增智能体模式：AI 解析协议帧结构、自动填充规约表单页面内嵌面板LangChain4j 初版集成
v2.2悬浮机器人 + 大模型配置动态化 + 节点/规约管理增强右下角悬浮机器人JDK 21 + Spring Boot 3.5 + LangChain4j 1.18
v3.0.1AI 智能体版本（2026-08-12 发布）：内嵌 LangChain4j 智能体、多模型配置、SSE 实时推送、前端构建集成进 Maven右下角悬浮机器人同上
v3.0.2（当前）控制通道反转、高级规约、流式思考 / 多轮对话 / 对话落库、初高级规约自动判断可拖拽悬浮机器人（含停止按钮）同上

v3.0.2 的重要更新：

  1. 控制通道反转：删去网关主动注册与心跳上报链路，改为 Console 主动探针（10s）与主动下发指令（HTTP 10917），并带差量补发与自动补发
  2. 高级规约：支持自定义长度域解析实现，适配非固定长度域报文（如 3761），前端提供代码模板与在线编辑
  3. 智能体能力跃升：流式输出 + 思考过程（可折叠、自动滚动、可停止中断）、多轮对话（补充信息去重、上限 12 条）、初/高级规约自动判断与一键创建、缺参追问与默认值告知
  4. 多模型配置：ai_config 由单行扩为多行（新增 name 列），对话面板可切换模型，设置面板改为模型列表管理，API Key 脱敏回显
  5. 对话记录落库：新增 ai_chat_message 表，流式解析连同思考过程一并存库，可按会话查询
  6. 构建集成：frontend-maven-plugin 让 mvn package 自动执行 npm install + vite build，前端产物打进同一个 jar（可用 -Dskip.frontend=true 跳过）
  7. 界面细节：悬浮球可拖拽（移动 > 4px 不触发开关）、面板按上下空间自适应弹开、思考区自动滚动

技术栈​

  • JDK 21（Temurin 21 LTS 及以上）+ Spring Boot 3.5
  • LangChain4j 1.18（AiServices 声明式结构化输出）
  • 前端 Vue3 + Vite 单页应用，源码位于 frontend/，构建产物输出到 src/main/resources/static/
  • MySQL 8.0+（规约策略、节点、对话记录存储；建表脚本使用 utf8mb4_0900_ai_ci，5.7 及以下导入会报错）
  • 入口类：IotGateConsoleApplication
